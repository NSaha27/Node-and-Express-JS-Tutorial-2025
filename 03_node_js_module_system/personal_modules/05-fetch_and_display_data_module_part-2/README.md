# FETCH AND DISPLAY DATA

---

## Key Points of this project

- There will be a Welcome page, which will have a "Get Started" button, upon clicking which the user will be redirected to the products page
- In the product page, all the products will be listed. There will be an "Add to Cart" button for each of the products. Upon clicking the Add to Cart button, the product will be saved to the cart.
- On each page, except the welcome page, there will be a Navbar containing links for redirecting to another page. There will be three page links, the home page link, the product page link, and the cart page link.
- On visiting the cart page, the user will be able to see all the products he has added to cart. Each product in the list must have an increment and a decrement button to update the number of products added to the cart. There will be a Delete button to delete a product permanently from the cart. There will also be additional two buttons, one for Checking Out for payment and another for Continuing the shopping.
