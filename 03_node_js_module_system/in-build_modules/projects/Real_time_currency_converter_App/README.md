# REAL-TIME CURRENCY CONVERTER

---

## Topic -

It is a cli-based app that converts amount of one currency to that of another currency, using real-time data fetched from an external API source.

### Points :

- There will be one fixed currency format, upon which the user has to enter his/her amount
- Then the user has to enter the destination currency, at which he/she wants to change the amount
- The program will then convert the amount into the destination currency
